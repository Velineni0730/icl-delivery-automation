# ICL Delivery Automation

Prototype for automating courier delivery sheet processing using:

- React
- Tailwind CSS
- Node.js
- Express.js
- Python
- Gemini 2.5 Flash
- Microsoft Graph API
- MongoDB Atlas
- Firebase

AI-powered courier delivery automation system that extracts shipment details from delivery sheets using Gemini OCR, automates pricing calculations, and streamlines courier operations with secure staff authentication.
